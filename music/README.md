The plugin ships `christmas-lofi.mp3`, a ~36-minute mix of CC0 and CC BY 4.0 lofi tracks
(see [CREDITS.md](CREDITS.md)), and plays it on loop by default.

To play your own music instead, drop one audio file (.mp3, .m4a, .aac, .wav, .aiff or
.flac) into `~/Music/Claude Christmas`. That folder is checked first and survives plugin
updates; with several files there, the first by name is used.
