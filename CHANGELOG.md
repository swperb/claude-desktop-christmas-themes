# Changelog

All notable changes to this plugin. Versions follow [Semantic Versioning](https://semver.org):
a hotfix bumps the patch number, a new theme bumps the minor number.

## [Unreleased]

## [0.2.0] - 2026-11-16
### Added
- Bundled **Christmas Lofi** mix (~36 min) of CC0 tracks by HoliznaCC0 and CC BY 4.0 tracks by Lobo Loco, playing by default. Credits in `music/CREDITS.md`.

## [0.1.0] - 2026-11-16
### Added
- **Snowy Night** theme: moonlit snowfall, snowmen, a glowing cabin, and Santa crossing the moon.
- **Cozy Fireplace** theme: crackling fire, stockings, a sleeping cat, a twinkling tree, snow outside.
- Christmas control pane: switch themes, play/pause, and step the volume.
- Bring-your-own music: any audio file in `music/` loops behind the themes, resuming where it paused when ffmpeg is installed.
- `/christmas` command for themes, music and volume.
